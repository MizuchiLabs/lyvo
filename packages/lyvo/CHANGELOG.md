# Changelog

All notable changes to `@mizuchilabs/lyvo` are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Fixed
- Java and C# code samples with a request body didn't compile.
- Code samples send form and multipart bodies as such, not as JSON.
- The localized docs index dropped the locale when its first page wasn't translated.
- Two operations or models with the same slug no longer share one page. The second gets a `-2` suffix and the build warns.
- OpenAPI `input` paths resolve against the project root, not the working directory.
- A spec prefix like `/apiv2` is rejected instead of being routed as `/api/v2`.
- "Copy page" works in Safari.
- A malformed external link no longer fails the build.
- Matomo tracks client-side navigations after its script has loaded.
- Codeberg repos get edit and issue links.
- The notice on untranslated pages names the original language in the page's language ("Englisch", not "English").
- API reference pages, the theme toggle, breadcrumbs, the footer and a few other places no longer have hardcoded English. Every UI string goes through `i18n.ui`.
- Changelog dates follow the page language instead of always `en-US`.
- Counts use plural forms, so a spec with one endpoint says "1 endpoint".

### Changed
- More UI strings are translatable: `copyCode`, `moreActions`, `server`, `authorization`, `username`, `password`, `body`, plus new keys for the API reference. All keys are listed in `src/lib/ui-strings.ts`.
- Unknown `i18n.ui` keys fail the build. The unused `reference` key is gone.
- `i18n.ui` strings can take plural forms, like `{ one: '{count} Endpunkt', other: '{count} Endpunkte' }`.
- `lastUpdated` takes a `{date}` placeholder. Old values without it still render, with the date after the text.
- Invalid locale codes like `pt_BR` fail the build instead of crashing pages that format dates.
- Components read the locale from the URL. `PageHeader` and `BaseHead` no longer take `lang`, `ThemeSwitch` and `PageActions` no longer take `locale`.
- `.mdoc` files are no longer picked up by the docs collection.

## [0.3.0] - 2026-09-29

### Migrating from 0.2

- `docs.sidebar` is a plain array now: `sidebar: ['intro', ...]` instead of `sidebar: { items: [...] }`. The `order`/`labels` form is gone. Leave `sidebar` out to get an automatic sidebar sorted by frontmatter `order`.
- `i18n.defaultLocale` is removed, use `lang`.
- `extraLinks` is removed, use `nav`. Its links also show in the docs sidebar footer.
- `og` only takes an object: `{ generate?, image? }`. `og.siteName` and `og: true` are gone. OG images are generated by default.
- `cacheHeaders` is removed.
- Analytics are self-hosted only: `umami.src`, `plausible.src`, `posthog.host` and `matomo.url` are required.
- Keep `sharp` in your project, Astro's image optimization needs it there.
- Remove `@tailwindcss/vite` from your Vite plugins and `@import 'tailwindcss'` from custom CSS. Lyvo sets up Tailwind itself.
- Unknown or misspelled options now fail the build instead of being ignored.

### Added

- Landing blocks: `FeatureSplit`, `CodeWindow`, `BrowserFrame`, `LogoCloud`, `InstallCommand` and `LinkButton`. `Hero` and `CTA` got a grid backdrop, a linked badge, an install command and a media slot.
- OpenAPI: a "Try it" playground, model pages for every schema, configurable snippet languages and server URL variables.
- SEO: hreflang, JSON-LD, `og:type`, `og:locale`, image sizes, `robots.txt` and a default 404 page. Untranslated fallback pages point their canonical at the original.
- LLMs: a Markdown version of every docs and API page (`/docs/intro.md`), a richer `llms.txt` and `llms-full.txt`, and "Copy page" / "Open in ChatGPT or Claude" actions.
- Navigation: section picker for guides and API versions, search in the sidebar, page icons and badges from frontmatter, a language menu that marks untranslated pages, a light/dark/system theme switch and a native `<dialog>` drawer on mobile.
- Astro `base` support across all links and generated files.
- `lyvo:track` events and a generic analytics bridge, feedback comments, issue links and remembered votes.
- A "Skip to content" link.

### Changed

- Analytics only load in production builds and default to private settings (no cookies, Do Not Track honored).
- Canonical URLs follow Astro's trailing slash output, matching the sitemap.
- The package only ships `src` and `types.d.ts`.

### Fixed

- OG images for pages without a generated image, and titles with `&` rendering as `&amp;`.
- An invalid OpenAPI spec now fails the build instead of silently dropping the API reference.
- Nested `<Tabs>`, localized sidebar links, nested sidebar groups and the default-locale language link.
- apiKey snippets used the scheme name instead of the header name, and Python snippets used JSON literals.
- Feedback button colors, which were never applied.
