Willkommen bei **Lyvo Docs**, einer schlanken, performanten und minimalen Dokumentationsvorlage für **Astro** und **Tailwind CSS**. Sie ist so konzipiert, dass sie so nah wie möglich an einer "Drop-in"-Lösung ist und gleichzeitig grenzenlose Anpassbarkeit durch reinen Code bietet.

<Callout type="success" title="Bereit loszulegen?">
	Lyvo Docs gibt dir die volle Kontrolle über deine Dokumentation. Du erhältst ein schönes Design
	ab Werk, mit der Freiheit, jede einzelne Komponente anzupassen.
</Callout>

## Warum Lyvo Docs?

Es gibt viele Dokumentationsgeneratoren wie Starlight, Docusaurus und Nextra. Lyvo Docs verfolgt einen anderen Ansatz: **Einfachheit und Kontrolle**.

Statt alles hinter komplexen Konfigurationsdateien zu verstecken, erhältst du den Quellcode für deine Layouts und Komponenten. Du besitzt den Code. Wenn du ändern willst, wie die Sidebar funktioniert, öffnest du einfach die Sidebar-Komponente und änderst sie.

### Diese Seite ist Deutsch

Diese Seite demonstriert die i18n-Unterstützung: Der Inhalt liegt unter `src/content/docs/de/` und wird unter `/de/docs/` ausgeliefert. Die Übersetzungen für UI-Texte stammen aus der `i18n.ui`-Konfiguration.
